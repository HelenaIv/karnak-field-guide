# Valley of the Kings – collecting area

Started 2026-11-17. Content for a Valley of the Kings guide, kept inside this repo so it can later share the site, build scripts and design with the Karnak guide.

Status: collecting only. Nothing here is read by `validate_content.py` or `build_review_site.py` yet; how it joins the site (new section of this site or a parallel content tree) is still an owner decision.

Rules are the same as for Karnak (see `docs/RECOVERY.md`): every fact sourced, English and Ukrainian together, original drawings only, high-quality photos only and no reused photos, ask the owner instead of guessing.

## Images
- Originals and downloads: `E:\Karnak\images\valley-of-the-kings` (never Downloads).
- Owner's own photos: `E:\Karnak\images\valley-of-the-kings\own`.
- Download: add `name.jpg https://commons.wikimedia.org/wiki/Special:FilePath/<File>?width=2560` lines to `urls.txt` in that folder, then the owner double-clicks its `fetch.cmd`. Contact sheets go to its `_qa\`.
