# Research and editorial standards

## Purpose

Make the ancient site legible **at the place where an object or scene is found**, without blending evidence, conjecture, and modern travel lore.

## Content evidence ladder

1. **Primary material**: surviving monuments, photographs, facsimiles, epigraphic editions; identify exact position and edition/plate.
2. **Scholarly argument**: excavation reports, catalogue entries, peer-reviewed books and institutional research.
3. **Institutional interpretation**: museum and project educational resources, clearly labeled.
4. **Secondary overview**: use only to locate stronger sources, never as sole basis for a specific ancient quotation.

A source ID should back every factual paragraph or grouped observation. Citation to a large website is not a substitute for a specific document when translating inscriptions.

## Four separate layers

- **Observation**: what is physically present; do not invent what a visitor can see from public walkways.
- **Text**: literal hieroglyphs / transliteration / translation only when checked against an epigraphic edition; record reading direction, damaged text and uncertainty.
- **Interpretation**: what scholars infer and why.
- **Uncertainty**: debated dating, restorations, altered reliefs, missing data and unresolved reading.

## Hieroglyph rules

- Do not use Unicode hieroglyph strings, Gardiner sign codes, translations or pronunciation guides unless checked against a published edition for that **specific** inscription.
- Use conventional Egyptological transliteration with a consistent editorial style; never equate English approximations with the original reading.
- Explain royal **prenomen** versus **nomen**, and distinguish a cartouche from surrounding divine epithets.
- If an inscription is inaccessible, repainted, damaged or altered, state it.
- Photograph/transcribe from a licensed image or academically published facsimile; do not silently reconstruct missing signs.

## Location & access rules

- Field-guide entries need wall face, compass orientation and register/column number **only where independently supported**.
- A citation's plate number is an **edition reference**, not necessarily a physically posted monument label.
- Never promise a scene is visible, illuminated, approachable or accessible today without current field verification.
- Where a gallery has restricted access, route must not presume entry.

## Media & rights

Images from academic sites/books are **reference material** unless reuse licensing is confirmed. Never commit downloaded images to this repository based on availability alone. Store provenance and licensing independently from factual citation.

## Source update and fact checking

Record exact source URL and access date. Historical construction dates and reign dates vary by chronology: prefer source-specific estimates, label ca. where appropriate, and avoid mixing incompatible regnal chronologies. Every claim should survive a second check before user-facing publication.

## Review checklist

- [ ] Exact referent identified
- [ ] Claims linked to relevant sources
- [ ] Physical location supported
- [ ] Original text and translation verified separately if included
- [ ] Uncertainty and alterations documented
- [ ] Access, viewpoint and preservation checked if claimed
- [ ] Image permissions checked
- [ ] English copy edited; editorial status updated
